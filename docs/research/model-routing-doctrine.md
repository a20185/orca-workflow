# 模型路由候选与提示词分层（2026-11-14）

本文件只记录候选路由，不表示已验证最优分工。`~/.cenv/*.json` 是 claude 启动时的 settings 注入文件，使用时必须传绝对路径；不读取或复制文件内容。

## 候选分工

- **deepseek（local.json）**：明确规格后的实现执行，价格较低、速度较快。
- **kimi-for-coding**：次复杂场景的分析和设计。
- **k3.1-pro**：计划、方案讨论和复杂规划。
- **GLM（glm/glm2）**：复杂 research、信息采集与自动评测。
- **omp**：实现层 Agent 派发。
- **codex**：审阅层 Agent 派发。

## 提示词分层

提示词按“角色 × 阶段 × 复杂度”组织，而不是按模型名绑定。简单任务强调明确文件、验收和停止条件；中等任务增加影响面和方案比较；复杂任务增加多方案证据、复核和停止规则。模型通过 settings 文件切换，评审标准不随模型改变。

## 实验纪律

一次只改变一个主要变量（模型通道或提示词类型），指标包括任务成功率、一次通过率、返修轮数、成本、时延、越界率和证据完整性。未达到样本量或证据不足时只能暂缓，不宣称最优。方案设计者和最终评估者分离，原始结果不可改写。
